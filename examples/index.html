🚀 How it Works

Welcome to your git-forest instance. This server is its own Git remote. The filesystem is the router, directories are isolated components, and git push is the deployment mechanism.

  • Folders are Routes: Create a directory with an index.js to spawn a new isolated worker.
  • Files are State: Store data in Markdown, JSON, or SQLite right next to your code.
  • Git is the Pipeline: Push to this server to instantly deploy code and data with zero-downtime hot-reloading.

🔌 Connect & Deploy

To start building, clone this live server to your local machine. Use the GIT_SECRET you configured in your deployment environment as the password.

git clone https://forest:<your-secret-token>@<your-domain.com>/git my-forest
cd my-forest

Create a new folder, add an index.js, commit, and push. Your component will be live instantly.
